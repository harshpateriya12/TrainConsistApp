## Overview

This use case demonstrates **manual sorting using the Bubble Sort algorithm** to arrange passenger bogie capacities in ascending order.

## Goal

Sort bogie capacities without using built-in sorting methods, helping understand how sorting algorithms work internally.

## Actor

User

## Flow

1. User provides passenger bogie capacities.
2. System compares adjacent elements in the array.
3. If elements are in the wrong order, they are swapped.
4. Multiple passes continue until the array becomes sorted.
5. Sorted capacities are displayed.

## Key Concepts

* Bubble Sort Algorithm
* Nested loops
* Swapping values
* Array manipulation
* O(n²) time complexity

## Example Output

**Before Sorting**

```
[72, 54, 60, 48]
```

**After Sorting**

```
[48, 54, 60, 72]
```
