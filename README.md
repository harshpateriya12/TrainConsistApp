## Overview

This use case uses **Java Stream API** to filter specific bogies from a collection in the Train Consist Management System.

## Goal

Retrieve bogies that satisfy certain conditions using the **`filter()` operation**.

## Actor

User

## Flow

1. User provides a collection of bogies.
2. System processes the collection using **Stream API**.
3. The `filter()` method selects bogies based on a condition.
4. Filtered bogies are displayed.

## Key Concepts

* Java Stream API
* `filter()` operation
* Functional programming style
* Collection processing

## Example Output

**Filtered Bogies**

```
Passenger Bogies:
Sleeper
AC
General
```
